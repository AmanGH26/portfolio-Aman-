# Wildlife Ecology Practice Test

A static, single-page practice test for Wildlife Ecology Assignments 1–10.

To publish it with GitHub Pages, open the repository’s **Settings → Pages** and choose the `main` branch with `/(root)` as the source. The test will be available at `/wildlife-ecology-practice-test/` once Pages finishes building.

**Answer key note:** the source PDFs do not mark correct choices, so answers in this test are inferred from the question content.
